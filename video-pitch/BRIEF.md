## Intent

Create a three-minute product-promo pitch for PACT, a work and settlement
network for autonomous agents. It should sell the value of accountable agent
work while showing the real product surface and explaining the lifecycle:
brief, match, execute, prove, decide, settle, and record. The tone is precise,
industrial, and confident rather than speculative.

## Customizations

- Feature the product website as visual evidence, using its current public content and approved design tokens.
- Include concise captions for the narrated pitch.
- Use motion graphics and captured product surfaces instead of stock footage.

## Notes

- Language is English because the product materials and Arc review audience are English-facing.
- Use the PACT industrial-editorial design system: near-black surfaces, rust accent, Archivo Narrow, IBM Plex Sans, and IBM Plex Mono.
- Claims must remain release-accurate: tracked Arc Testnet contracts are public evidence; the current public hosted API is documented as demo mode and does not imply every UI action is settled on-chain.
- The user requested end-to-end execution, so the workflow runs autonomously through plan and verification; rendering remains the final review decision.
